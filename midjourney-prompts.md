# AIMKT — Midjourney Prompt Guide (v3)

TIP: 只复制每条 prompt 的纯文本，不要复制标题和分隔线。不带任何参数。

设计方向：真实编辑摄影风格，参考 Vogue / Wallpaper* / Apple / SSENSE 的视觉语言。每条 prompt 描述一个可以在真实摄影棚或实地拍摄的场景，确保科技感 + 时尚感 + 创意感。

## 风格说明

这批 prompt 的核心策略变化：

| 之前的问题 | 现在的解法 |
|-----------|-----------|
| 抽象概念（液态水银、丝绸悬浮） | 真实场景（摄影棚、办公室、工作室） |
| "long exposure" 运动模糊 | 静态编辑摄影，用构图创造动态感 |
| "quiet luxury, understated elegance" 重复堆砌 | 具体杂志风格引用（Vogue, Wallpaper*, SSENSE） |
| 没有具体拍摄参数 | 指定相机 + 镜头 + 光圈 + 布光 |
| 太像艺术装置 | 像真实品牌 Campaign 照片 |

**关键参考品牌/媒体**：Apple 产品摄影、Vogue Italia 编辑大片、Wallpaper* 室内摄影、SSENSE 时尚电商、Kinfolk 生活美学、Dezeen 建筑摄影、Monocle 商业编辑
